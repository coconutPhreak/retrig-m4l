# Retrig

Elektron-style retrigs for every pad in an Ableton Drum Rack, as a Max for Live MIDI effect.

> Work in progress.

## Features (planned)

- Per-pad retrigs: drop one instance into each pad's chain, before the instrument
- RATE, LEN, velocity fade (VFAD) and a linear-to-exponential fade curve (CRV)
- Every control p-lockable per step via Push step automation or clip envelopes
- Works on Push 3, in Standalone and Control Mode

## Requirements

- Ableton Live 12 Suite (or Standard with Max for Live)

## Install

Download the latest `.amxd` from Releases and drop it into a Drum Rack pad's chain, before the instrument.
